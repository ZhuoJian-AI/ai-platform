第一章　企业基本情况与业务痛点

敏睿文具是一家书写工具进口贸易与 B 端分销企业（POC demo），核心负责全系列书写工具的进口贸易、全国 B 端分销网络运营、KA 大客户管理及渠道品牌管控。营收以 B 端渠道为载体，覆盖经销商体系、大型零售连锁、政企采购等多元 B 端客户。

核心业务链路

对日进口采购 → 报关单证 → 仓储库存 → 经销商/KA/电商分销 → 渠道秩序与防伪维权 → 售后服务 → 财务对账回款。环环相扣，任一环节信息滞后都会放大经营风险。

第二章　九大场景的 AI 解决方案

九个场景都用同一种终端任务方式：业务用户用自己的归口账号登录终端，新建一个任务、选好模型（glm-5.2）、粘贴一段很短的提示词（写明"要做什么 + 针对哪些对象"后用 /技能名 引用技能）即可运行。智能体会自主判断该调哪些业务系统、按什么顺序查，跨系统把数据凑齐，边算边输出结构化结果，最后自动生成一份 .docx 报告可直接下发。提示词之所以能写得很短，是因为"输出格式、业务名词字典、智能体人设与规则"已由平台和模板预先配好，用户只补"本次目标"。

📖 名词速查
产品码（SKU-ZB-）：文具产品主数据码，如 SKU-ZB-G001（中性笔 0.5 黑）；与 ERP 物料码 M-ZB- 不同码空间，按 product_code/material_code 关联。
经销商（DLR-）/KA（KA-）：B 端客户码，DLR- 经销商、KA- 大客户、EC- 电商授权店、EXP- 海外。
报关单（CD-）：进出口报关单号，如 CD202607001，引用采购单 PO-；发票 INV- 关联凭证 BV-AS-。
假货样本（CTF-）：抽检/维权取证样本码，如 CTF20260701；其 evidence_code 关联渠道取证 EV- 与违规商家 MR-。
归口部门：负责某项业务的部门，每个场景由一个归口部门用自己的账号去跑。
vibe working：AI 作员工副驾驶辅助日常工作，不对终端客户直接交互。
RAG：检索增强生成——先在企业知识库检索相关内容、再据此作答，而非凭空编。
本体：用 Markdown 写的业务"字典"，告诉 AI 每个业务名词是什么、有哪些字段和编码规则。
端点/技能（skill）：业务系统查询接口；一组端点打包成"功能工具"，智能体用 /技能名 引用。
流式输出：AI 边算边把结果一段段吐出，不用等全部算完。
作用域（scope）：资源可见范围，按 组织→部门→团队→用户 逐级限定。
glm-5.2：本 POC 使用的大模型（智谱出品），终端下拉直接列真实模型 id。

3.1 平台总览与四组件

平台是一站式 AI 基础设施，提供大模型路由、智能体编排、工具接入与应用监控四类能力，由五个子系统共享同一套后台控制台与基础设施（数据库 PostgreSQL + 缓存 Redis + 向量库 pgvector）。

子系统定位核心能力
组织管理权限地基组织→部门→团队三级层级、管理员与用户管理、速率/预算限额逐级收紧
模型路由器统一大模型中转API Key、模型提供商、DLP 安全围栏、模型路由与用量管控
智能体平台智能体编排工作空间、智能体配置、RAG 知识库、长期记忆
工具连接器业务系统接入数据接口、技能（功能工具）、本体
应用监控台三子系统统一看板调用量、Token、延迟、错误率、DLP、成功率

敏睿文具采用四层提示词架构：L1 短 composer（用户终端只写"目标+对象+/技能名"）/ L2 模板四段 system_prompt（人设/职责端点链/检索 RAG/业务规则/输出格式，落在归口部门智能体模板）/ L3 org-scope identifiers.md（业务名词字典+跨码空间映射，组织本体全员可见）/ L4 数据接口目录（可用端点，组织级全员可见）。喂 LLM 的内容不含场景代号（SAL-01 等），用具体示例码（DLR-01 / SKU-ZB-G001 / CD202607001 / CTF20260701），避免模型臆造编码导致 404。

3.2 组织管理

🔒 为什么"分级 scope"是安全的
  • 最小可见面：业务用户只能看到本部门 / 团队被显式授权的技能与 RAG，跨部门敏感数据（如假货样本库对销售部、合同条款库对产品部）默认不可见。
  • 技能层隔离：7 套系统组织级共享，但部门级技能只绑本部门授权端点子集——销售部技能只调 CRM+ERP 客户/库存、产品部技能只调 PIM 全端点，暗箱穿透被技能 scope 阻断。
  • API Key 分团队签发：15 个团队级 Key + 组织级默认 Key，各自 RPM/token 预算上限，单团队异常不影响其他部门。
  • DLP 围栏组织级生效：经销商名单、供应商报价、发票凭证等敏感数据外发规则按范围配置，越权外发即阻断/告警。

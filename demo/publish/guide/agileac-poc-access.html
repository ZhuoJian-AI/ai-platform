四、POC 验证建议步骤

  1. 打开业务终端登录页，用任一归口用户登录（建议先用 svc-engineer 跑 SVC-01，或 sal-ops 跑 SAL-02 报销问答）。
  2. 新建任务 → 模型选 glm-5.2 → 粘贴指南第二章对应提示词 → 在输入框敲 / 选择要用的技能 → 提交运行。
  3. 观察流式输出：会看到 [tool_call] 调用业务系统 → 结构化结果表 → [final] 生成 .docx 报告。
  4. 切换其他归口用户重复验证其余场景，体验“分级 scope 只能看本部门资源”。
  5. 如需查看管理端配置（模型路由/智能体/工具/监控），联系平台方现场引导。

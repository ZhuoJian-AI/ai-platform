- 工具响应先完整配对，再追加纠错反馈，避免兼容供应商拒绝消息序列。
- 写操作在外层执行超时时，本轮不自动再次提交同一工具，提示只读核实结果。
  这不是跨运行的完整超时对账；业务 Action 内部超时状态与持久幂等仍待单独验证。
- 兼容供应商不默认声明支持 strict；服务端参数校验继续保留。
- 侧栏新建会话在流开始前保存 URL conversation；Artifact 合并按文件与版本去重。
- 本轮产物从完整、经权限校验的文件操作记录收集，不被后续读取旧版本覆盖。
- 预览和下载使用卡片对应版本；工具调用状态不冒充任务完成状态。
- 文件交付判定复用公共实现；明确请求的输出格式不能被不同格式替代。

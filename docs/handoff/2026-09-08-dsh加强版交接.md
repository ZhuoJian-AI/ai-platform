## 3. 发版步骤（升级 DSH 版本后专用，写在 `COOLIFY_DEPLOYMENT.md`）

1. 合并 PR #13 到 main。
2. 服务器上从 main 检出，跑 `scripts/build-dsh-runtime-deps.sh`（校验 vendor 校验和、构建、校验镜像内 dsh-agent-loop 版本、推 registry）→ 输出 `AI_PLATFORM_DSH_RUNTIME_DEPS_BASE=<digest>` 与完整的 app 镜像构建命令。

5. 验收：backend 启动日志出现 baseline 自愈到 rc.8 的记录；`GET dsh-runtime /health` 报 `0.1.0-rc.8`；终端跑一轮带技能的任务；触发一次删文件看审批卡。

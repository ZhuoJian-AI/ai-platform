# 企业 AI 底座用户手册（企业管理员）

本文对应当前 9 服务版 AI Platform。企业管理员只管理绑定企业，不能查看或修改其他企业。

## 1. 登录与权限边界

- 登录入口：`/{企业标识}/login` 或平台分配的企业管理入口。
- 企业管理员与普通员工是两类独立账号；需要使用业务终端时仍应配置员工身份。
- 企业管理员的 `*` 表示本企业全部部门工作空间读取、上传和修改，不包含共享文件删除，也不自动批准新应用页面和 Action。
- 管理页面与后台接口都执行服务端权限检查，隐藏入口不等于已经授权。

## 2. 企业、部门和员工

### 2.1 组织架构

维护本企业部门层级、部门状态和员工主部门。员工只归属一个主部门；跨部门访问由角色权限授予，不通过重复部门归属实现。

### 2.2 员工授权

企业管理员可以创建、编辑、启停和删除员工，调整主部门，绑定或撤销角色，重置密码。一个员工可以拥有多个角色，最终权限取并集。

角色或员工状态变化会更新 `auth_epoch`；撤权后下一次请求必须立即拒绝，旧页面缓存不能继续越权。

### 2.3 角色权限

角色权限包括三部分：

1. 部门及企业公共工作空间能力；
2. 企业应用、模块和页面可见性；
3. 页面 Action 执行权限。

新接入页面和 Action 默认无权。管理端“模拟员工查看”与员工端调用同一权限服务；界面显示与真实接口不一致时应视为缺陷。

### 2.4 企业资料、联系方式和管理员

企业资料与联系方式用于维护本企业展示和联系信息。管理员页面用于维护本企业管理员，不应在此创建普通业务员工。

## 3. 企业应用

### 3.1 应用与 Manifest

企业应用由 Runtime 同步 Manifest，平台展示模块、页面和 Action。企业管理员审核后再通过角色授权给员工。

### 3.2 SSO、Bridge、Action 和 Event

- 员工从企业终端打开嵌入页面时使用一次性 SSO。
- Bridge 只传递当前员工、应用、模块、页面和短时上下文。
- Action 每次调用都重新检查当前角色和数据范围。
- Event 用于受控业务事件接入，不得携带平台模型密钥。

业务系统只负责权限过滤后的业务数据和业务动作；平台负责模型调用、文件执行、工作空间与 Artifact。

## 4. 模型与安全

### 4.1 API Key 与模型提供商

平台 API Key 服务公开 `/v1` OpenAI/Anthropic 对话兼容调用。模型供应商集中保管 LLM、多模态、图像和音频等模型凭据，企业业务系统和员工浏览器不接触供应商密钥。平台不再提供 Embedding 模型配置和专用调用。

### 4.2 安全围栏、额度与审计

所有模型调用经过 DLP、路由、额度和审计。出现失败时应根据中文错误和审计记录判断，不把所有 409、422 或上游错误都解释成权限不足。

## 5. Assistant Core

### 5.1 工作空间

工作空间保留个人、部门和企业公共空间，以及文件夹、文件、版本、OSS、预览、下载、回收站和恢复。Office/PPT 只读预览仍保留；在线协作编辑已经退役。

默认权限：

- 个人空间：本人读写；
- 主部门空间：员工默认只读；
- 跨部门和企业公共空间：按角色授权；
- 企业管理员 `*`：本企业全部部门工作空间读取、上传和修改。

### 5.2 个人助手、业务小助手和自定义智能体

三种助手都由原生 Assistant Core 执行：

- 个人助手：个人工作空间、平台固定工具、Web、多模态和长期记忆；
- 业务小助手：Bridge 当前页面上下文和实时授权的 Manifest Action；
- 自定义智能体：只保存文本角色提示词，运行时继承当前员工个人助手的模型选择、平台固定工具和实时权限。

业务小助手生成文件时，必须真实写入员工有权工作空间并返回可预览、可下载 Artifact；只有文字说明或服务器路径不算完成。

### 5.3 长期记忆和固定工具

长期记忆按企业和员工身份隔离。平台固定文件工具由受控执行器运行；平台不再提供知识库/RAG、用户 Skill 上传或任意脚本执行。

## 6. 监控和 Runtime

- 总览：服务健康和关键状态。
- 路由器监控：模型请求、延迟和错误。
- 智能体监控：任务、运行及事件。
- 工具监控：平台固定工具和 Manifest Action。
- Runtime 管理与 ECS Publisher：子系统登记、发布和诊断。

## 7. 员工终端验收

员工终端提供企业应用、个人助手、跨部门待办、工作空间和文本型智能体。管理员完成授权后，应使用独立员工浏览器会话验证：

1. 页面和 Action 是否按角色显示；
2. 工作空间目录与文件接口是否一致；
3. 撤权后下一次请求是否立即失败；
4. iframe、SSO 和 Bridge 是否正常；
5. 业务助手是否只获得当前页面 Action；
6. 文件型任务是否交付真实 Artifact；
7. 错误密码、权限不足、冲突和参数错误是否显示中文提示。

## 8. 已退役能力

DSH Runtime/市场/外部扩展、Connector、Tool Endpoint、Data Interface/Data System、Ontology、Judge、管理员测试广场、MCP/OAuth Skill Pack、Team、ScopeManager、旧模块发布器和 WebOffice 在线协作编辑均已删除。

历史审计和迁移文档可能保留旧名称用于追溯，不代表功能仍存在。

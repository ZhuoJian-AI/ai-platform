# 工具连接器 (tool_connector)

AI Infra 平台的子系统之一，负责工具与外部能力的统一接入与调用。

## 定位

为大模型与智能体提供统一的工具调用层：标准化工具描述、鉴权、超时/重试、调用审计，以及与 MCP（Model Context Protocol）等协议的桥接，使上层子系统无需关心具体工具的实现差异。

## 规划范围

- 工具注册与版本管理（HTTP / 函数 / MCP 工具）
- 统一调用网关：鉴权、限流、超时、重试
- 工具沙箱与输入输出校验
- 调用日志与可观测性对接（应用监控台）
- MCP 服务器桥接
